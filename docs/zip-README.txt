OpenTakeoff {VERSION}
Free cockpit, moving map and automatic logbook for MSFS 2020/2024 and X-Plane 11/12
Design and development: redzikowski.com

==============================================================================
 WHAT'S INSIDE
==============================================================================

  OpenTakeoff-Setup-{VERSION}.exe   Windows program (installer)
  OpenTakeoff-{VERSION}.apk         Android app (Android 8.0 or newer, optional)
  README.txt                        this file

The Windows program works on its own. The Android app adds a cockpit,
controls and a logbook on your phone or tablet, and pairs with the PC
over your home Wi-Fi.

==============================================================================
 1. WINDOWS
==============================================================================

1. Run OpenTakeoff-Setup-{VERSION}.exe and follow the installer.
   If Windows SmartScreen warns about the file: More info -> Run anyway.
2. The installer allows OpenTakeoff through the firewall on PRIVATE
   networks only. Set your home network to "Private" in Windows
   (Settings -> Network & internet -> Wi-Fi/Ethernet -> Private network).
3. Start OpenTakeoff. It connects to MSFS 2020/2024 or X-Plane 11/12 by
   itself; the start order doesn't matter.
   - X-Plane: Settings -> Network -> accept incoming UDP connections
     (port 49000). No plugins needed.
   - No simulator at hand? Choose "Simulation" in the top bar to see a
     demo flight (EPWA -> EPGD).
4. Optional: start OpenTakeoff together with MSFS or X-Plane (Phones tab
   or Settings).

Your data (settings, logbook, screenshots) is kept next to the program in
the "data" folder. Uninstalling keeps your logbook and settings.

==============================================================================
 2. ANDROID (optional)
==============================================================================

1. Copy OpenTakeoff-{VERSION}.apk to the phone (USB cable, Google Drive,
   e-mail...) and open it.
2. Allow installing apps from this source when Android asks. You only do
   this once: the app is not on Google Play yet.
3. Pair with the PC: in the app open "Flight", pick your PC from the list
   (or type its IP address) and enter the 6-digit code shown on the
   "Phones" tab of the Windows program. The phone remembers the pairing.

The phone and the PC must be on the same Wi-Fi / home network (not a guest
network). Flights sync between the phone and the PC both ways.

There is no iOS version.

==============================================================================
 3. UPDATES - YOU ONLY DOWNLOAD ONCE
==============================================================================

- Windows: OpenTakeoff checks for a new version at startup and every
  6 hours and lets you choose: Install now / Later /
  Skip this version. You can also check by hand: Settings -> Check for
  updates.
- Android: the app checks at every start and installs a new version with
  one tap, over the current one.
- Your logbook and settings stay where they are.
- New versions are also posted on flightsim.to and on GitHub:
  https://github.com/BlackSingularities/OpenTakeoff/releases

==============================================================================
 4. UPGRADING FROM 2.6.4 (OpenTakeoff Link)
==============================================================================

OpenTakeoff Link has been replaced by the Windows program. Install it and
you can delete OpenTakeoff-Link.exe. Phones that were paired with Link
connect to the new program without a new code. Install the new APK over
the old app: your logbook stays.

 PO POLSKU

"Więcej informacji -> Uruchom mimo to". Sieć domowa w Windows ustawiona
jako "Prywatna". Program sam łączy się z MSFS 2020/2024 albo X-Plane 11/12;
bez symulatora wybierz "Symulacja" na górnym pasku (lot pokazowy).

z tego źródła. W aplikacji: "Lot" -> wybierz komputer z listy (albo wpisz
jego adres IP) -> wpisz 6-cyfrowy kod z karty "Telefony" w programie na PC.

Aktualizacje: obie aplikacje same sprawdzają nowe wersje i instalują je
na miejscu starej - dziennik i ustawienia zostają. Pobierasz tylko raz.
